# Password Hygiene Checker (Python)

A simple beginner-friendly Python script that checks whether a password
follows basic real-world security hygiene (not unrealistic rules).

This is meant for students learning cybersecurity and Python.

---

## What this script checks
- Minimum length
- Uppercase letter
- Lowercase letter
- Number
- Special character
- Warns about common weak passwords
